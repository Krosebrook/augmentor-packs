# Glossary (plain words)

Words you'll see around Claude Code and these packs, explained simply. In Claude Code you can also ask: "What does ___ mean?" and the `plain-glossary` skill will explain it.

### AI
Computer programs that do things we usually think need a person, like writing or answering questions. Like a very well-read assistant who sometimes guesses.

### Claude
An AI assistant made by the company Anthropic. You talk to it in plain language.

### Claude Code
A version of Claude that runs on your computer, in a terminal, the desktop app, or a code editor. It can read and work with files you allow.

### Prompt
What you type to ask for something. Clear prompts get better answers: say who it's for, what you want, why, and how it should look.

### Hallucination
When AI states something made up as if it were true, like a fake quote, a wrong date, or a link that doesn't exist. This is why you check names, numbers, dates, and links.

### Model
The "brain" behind the AI. Different models trade speed for carefulness.

### Terminal
A window where you type commands instead of clicking. On Mac it's called Terminal; on Windows, PowerShell or Command Prompt.

### Command (terminal)
A line you type in the terminal and run by pressing Enter, such as `claude --version`.

### Slash command
A shortcut you type inside Claude Code, starting with `/`, such as `/plugin` or `/ai-beginner-augmentor:start`.

### Plugin
An add-on that gives Claude Code new abilities. Like an app on your phone.

### Marketplace
A list of plugins you can install from. Like a shelf in an app store. This one is called `augmentor-packs`.

### Pack
What we call each plugin in this marketplace, such as `student-augmentor` or `office-augmentor`.

### Augmentor
A pack that helps you do your own work better (coaching, checking, drafting) instead of doing it for you.

### Skill
Written know-how inside a plugin. Claude uses it automatically when your request matches, or you can call it by name.

### Agent (subagent)
A helper with one narrow job that Claude can hand a task to, like the `answer-checker`.

### Scope
Where an installed plugin is turned on: just for you everywhere (user), for everyone in a shared project (project), or just you in one folder (local). Pick "user" if unsure.

### Context
Everything Claude can "see" in the current conversation. Very long chats can push early details out.

### Token
A small piece of text (about part of a word) that AI counts when reading and writing.

### Repository (repo)
A project folder tracked with a tool called Git, often stored on GitHub. This marketplace lives in the repository `Krosebrook/augmentor-packs`.

### GitHub
A website where people store and share repositories.

### MCP server
A small connector that lets Claude fetch outside information. Only the optional `tools-*` plugins use them. The beginner pack doesn't.

### Placeholder
A marker like `[CHECK: …]` or `[DATA NEEDED]` that the packs leave instead of guessing. Replace it with the real information, or delete it.

### PATH
A list your computer uses to find programs. If the terminal says `claude` isn't found right after installing, the fix is usually about PATH. See [troubleshooting](troubleshooting-for-beginners.md#claude-command-not-found).
