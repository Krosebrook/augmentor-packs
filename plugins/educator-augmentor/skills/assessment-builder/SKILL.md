# Assessment & Quiz Builder

## Blueprint first
Before writing items, produce a blueprint table: `objective | # items | item type | cognitive level (Bloom's/DOK) | points`. Confirm with the teacher. This prevents the common failure of a test that over-samples easy recall.

## Item-writing rules
**Multiple choice**
- Stem poses a complete question; put most wording in the stem.
- One clearly best answer; 3–4 options; distractors based on real misconceptions (state which one each targets in the key).
- Options similar in length and grammar; avoid "all/none of the above", double negatives, and clues like absolute words ("always").
- Vary the position of the correct answer.

**Short/constructed response**
- Specify what a full answer includes and the point breakdown; write a model answer and a partial-credit guide.

**Performance/application items**
- Use a realistic scenario; require the skill, not recall of the scenario.

## Content rules
- Use only content from the teacher's materials or stated curriculum. If you write a factual item from general knowledge, mark it `[verify]` so the teacher checks it.
- Reading load should match the grade unless reading is the skill assessed.
- Bias/accessibility check: culturally loaded contexts, unnecessary idioms, names/scenarios that stereotype, visuals without text alternatives.

## Output
1. Blueprint.
2. Student-facing assessment (clean, numbered, with directions and point values).
3. Teacher key: answers, rationales, misconception per distractor, rubric for open items.
4. Optional: a parallel version (Form B) for retakes, and export formats (plain text for an LMS quiz import, or a table).

For formative checks, add a "what to do next" note: if many miss item X, reteach Y.
