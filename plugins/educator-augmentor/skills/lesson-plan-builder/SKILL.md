# Lesson Plan Builder

## Standards rule
**Use only standards the teacher provides, quoted exactly with their codes.** Do not supply standard codes or wording from memory — frameworks differ by state/country and get revised. If none are provided, ask for them, or plan against teacher-stated learning goals and label the plan "not standards-aligned yet."

## Intake
Grade/course, standards (pasted), lesson length, where this sits in the unit (what came before/after), class profile (size, needs such as ELL/IEP/504 accommodations — no student names needed), available materials/tech, and any required curriculum.

## Build (backward design)
1. **Objective(s):** measurable, student-facing "I can…" statements using an observable verb at the right cognitive level (Bloom's revised taxonomy or Webb's DOK if the teacher uses it). Map each to the standard text.
2. **Evidence:** how you'll know they got it — the exit ticket/task, written first.
3. **Sequence** with minutes:
   - Hook/activation of prior knowledge (≤5 min)
   - Direct instruction / modeling (keep short — chunk at ~10 min)
   - Guided practice with a check for understanding (CFU)
   - Independent or collaborative practice
   - Closure + exit ticket
   Default model: I do / We do / You do; switch to inquiry-first if the teacher prefers.
4. **CFUs:** at least 2 planned checks with the exact question and what to do if <80% get it (reteach move).
5. **Differentiation:** supports and extensions (hand off to `differentiation-udl` for depth).
6. **Materials & prep list.**
7. **Anticipated misconceptions** with a response for each.

## Output format
One-page plan with: header (course, date, standard text, objectives), timed table `minutes | activity | teacher does | students do | CFU/materials`, exit ticket with answer key, and misconceptions. Offer a student-facing agenda slide outline.

The teacher is the professional: present options where pedagogy is a judgment call, and keep it realistic for the stated time.
