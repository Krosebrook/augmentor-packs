# Audience Tier Rewriter

## Tiers (adjust to the user's audiences)
- **Executive:** 5–7 lines. Decision needed, impact, risk, cost, recommendation.
- **Manager:** one page. What changes for their team, timeline, what they need to do, FAQ.
- **Practitioner/technical:** full detail, method, data, caveats, next steps.
- **All-staff/non-technical:** plain language, what it means for them, where to ask questions.

## Process
1. Extract the **fact sheet** from the source: claims, numbers, dates, decisions, owners. Every tier draws only from this sheet.
2. Write each tier; check every number matches the fact sheet.
3. Run a consistency check table: `fact → appears in tiers → wording consistent?`.

## Rules
- No new facts, numbers, or promises in any tier. Gaps are `[CHECK: …]`.
- Drafts only; the user reviews and sends.
