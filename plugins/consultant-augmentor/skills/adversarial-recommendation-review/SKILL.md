# Adversarial Recommendation Review

## Pass 1: claims and evidence
List each recommendation and claim. For each: evidence offered, evidence quality (measured, reported, assumed), and what would falsify it.

## Pass 2: assumptions
Surface implicit assumptions (budget, adoption, data quality, vendor roadmap, staffing). Mark which ones the plan collapses without.

## Pass 3: counter-case
Steelman the strongest argument against the recommendation and the best alternative (including "do nothing" and "smaller pilot").

## Pass 4: failure modes
Pre-mortem: "It is a year later and this failed. Why?" Top 5 causes with early warning signs.

## Output
Review memo: verdict (**Go** / **Go with changes** / **Rethink**), top issues with suggested revisions, confidence per recommendation (high/medium/low with reason), and open questions `[CONFIRM]`.

## Rules
- Critique the argument, not the author. Never invent counter-evidence; mark gaps `[CHECK: …]`.
