# Code Lookup Prep

## Code & safety boundaries
- Codes vary by jurisdiction and adopted edition (NEC, IPC/UPC, IMC/UMC, IRC, IECC, local amendments). **The Authority Having Jurisdiction (AHJ) and the locally adopted code govern.** Never quote a code section number, table value, or requirement from memory as fact — mark it `[verify: adopted code edition / AHJ]`.
- This pack does not replace licensed judgment, manufacturer installation instructions, permits, or inspections.
- Never invent prices, labor rates, material costs, or permit fees. Use the user's numbers; mark gaps `[DATA NEEDED]`.

## Steps
1. Clarify: jurisdiction (state/county/city), occupancy type, new vs. existing/alteration, and the specific installation question.
2. **Which code applies:** ask the user to confirm the adopted edition and local amendments (state licensing board or local building department website) → `[verify: adopted edition]`.
3. **Where to look:** describe the topic areas to search in the index (e.g. "working space around electrical equipment", "fixture unit sizing", "combustion air", "venting") and the kind of table likely involved. Present any article/chapter references only as *likely starting points* to confirm in the index, labeled `[verify]`.
4. **Related requirements** that often trip people up (listing/labeling and manufacturer instructions, local amendments, utility requirements) as questions to check.
5. **AHJ question draft:** a concise, specific question to email/call the building department or inspector.
6. If the user pastes the actual code text, help interpret its wording and structure (exceptions, definitions) while reminding them the AHJ's interpretation governs.

Never say "code requires X" without the user's pasted text as the source.
