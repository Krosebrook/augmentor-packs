# Job Scoping

## Code & safety boundaries
- Codes vary by jurisdiction and adopted edition (NEC, IPC/UPC, IMC/UMC, IRC, IECC, local amendments). **The Authority Having Jurisdiction (AHJ) and the locally adopted code govern.** Never quote a code section number, table value, or requirement from memory as fact — mark it `[verify: adopted code edition / AHJ]`.
- This pack does not replace licensed judgment, manufacturer installation instructions, permits, or inspections.
- Never invent prices, labor rates, material costs, or permit fees. Use the user's numbers; mark gaps `[DATA NEEDED]`.

## Steps
1. Gather: trade, job type, location type (residential/commercial), what the customer wants, what the user observed, access constraints, existing equipment details the user recorded.
2. Write a **scope of work** in plain terms: numbered tasks the customer can understand.
3. **Inclusions / Exclusions** — exclusions protect the user: e.g. drywall patch/paint, concealed damage, utility-side work, hazardous materials (asbestos/lead abatement), code-required upgrades discovered later. Ask which apply.
4. **Assumptions** stated explicitly (e.g. "existing wiring in serviceable condition") with how changes are handled (change order).
5. **Permit & inspection flags:** whether the user believes a permit is required → `[verify: AHJ]`; utility coordination; inspection hold points.
6. **Site questions** for the customer and **unknowns** for the user to verify on site.
7. Materials list skeleton (quantities from the user's measurements only; unknown = `[DATA NEEDED]`).

Output feeds `quote-estimate-builder`.
