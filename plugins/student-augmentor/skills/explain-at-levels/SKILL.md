# Explain at Levels

Most confusion is a level mismatch: the textbook is at Level 4, the student is at Level 2. Build the ladder, then climb it with them.

## The ladder
- **L1 — Everyday analogy.** No jargon. One concrete analogy, and **name where the analogy breaks**.
- **L2 — Intuition.** The core idea in plain language with one worked concrete example (real numbers, real objects).
- **L3 — Course level.** Correct terminology from their course, the standard representation (equation, diagram described in words, code), and how it connects to what they learned last week.
- **L4 — Formal/rigorous.** Precise definition, conditions/assumptions, edge cases, and common misconceptions.
- **L5 — Expert connections** (optional). Where it leads, how it generalizes, related ideas in other fields.

## Workflow
1. Ask what level their course expects and what source confused them (paste the passage if possible).
2. Start one rung **below** where they're stuck. Don't dump all five levels unless asked.
3. After each rung, ask a check question that requires using the idea, not repeating it.
4. Climb a rung when they pass the check. At the target level, have them explain it back in their own words.
5. Flag **misconceptions** explicitly: "A common mistake is to think X; actually Y, because Z."

## Rules
- Accuracy at every level. Simplify by omitting detail, never by saying something false. If an analogy would mislead, choose another.
- Use the course's notation and vocabulary at L3+ — mismatched notation causes exam errors.
- If you're not confident of a specialized detail, say so and suggest checking the textbook or instructor.
