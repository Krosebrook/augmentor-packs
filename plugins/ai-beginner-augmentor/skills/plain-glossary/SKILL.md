# Plain Glossary

Goal: any word, explained so a smart 12-year-old would get it.

## Format for each term
**Word**: one plain sentence. *Like:* an everyday comparison. *Why it matters to you:* one line.

## Starter entries
- **AI (artificial intelligence)**: computer programs that do things we usually think need a person, like writing or answering questions. *Like:* a very well-read assistant who sometimes guesses.
- **Claude**: an AI assistant made by the company Anthropic. You talk to it in plain language.
- **Claude Code**: a version of Claude that runs on your computer (in a terminal, desktop app, or code editor) and can read and work with files you allow.
- **Prompt**: what you type to ask for something. *Like:* the instructions you'd give a helper.
- **Model**: the "brain" behind the AI. Different models are faster or more careful.
- **Hallucination**: when AI states something made up as if it were true. *Why it matters:* always check names, numbers, and links.
- **Terminal**: a window where you type commands instead of clicking. *Like:* texting your computer.
- **Plugin**: an add-on that gives Claude Code new abilities. *Like:* an app on your phone.
- **Marketplace**: a list of plugins you can install from. *Like:* an app store shelf.
- **Skill**: written know-how inside a plugin that Claude uses when your request matches it.
- **Command**: a shortcut you type starting with `/`, like `/ai-beginner-augmentor:start`.
- **Agent (subagent)**: a helper with a narrow job that Claude can hand a task to.
- **Context**: everything Claude can "see" in the current conversation. Long chats can make it forget earlier parts.
- **Token**: a small piece of text (about part of a word) that AI counts when reading and writing.
- **MCP server**: a small connector that lets Claude fetch outside information. The beginner pack doesn't use any.

## Rules
- If you're not sure of a precise definition, keep it general and add `[CHECK: official docs]` rather than inventing detail.
- Offer to explain any word used in your own explanation.
- Never make the person feel behind for asking.
