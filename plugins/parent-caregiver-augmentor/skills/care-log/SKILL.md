# Care Log

## Setup (ask before creating files)
`care/<person>-log.md` with sections:
- **Key info:** providers and phone numbers, pharmacy, insurance (last 4 digits only), allergies, advance directive location, emergency contacts.
- **Medication list:** name, strength, schedule, prescriber, start date, purpose (as told by the clinician), changes.
- **Daily log:** date, time, observation (objective where possible: "ate half of lunch", "walked to mailbox"), meds given if tracking, mood, sleep.
- **Appointments:** date, provider, purpose, outcome, follow-ups.
- **Questions for next visit.**

## Use
- Add entries from the user's notes with dates. Don't add interpretations.
- **Summaries:** "What changed in the last 2 weeks?" → list observations with dates and counts (e.g. 3 dizziness entries) and suggest bringing them to the clinician. No diagnoses.
- Privacy: keep the file local; share only what's needed; avoid full ID/insurance numbers.
- Handoff sheet for a backup caregiver: routines, meds schedule (as written), contacts, what to do in an emergency.
