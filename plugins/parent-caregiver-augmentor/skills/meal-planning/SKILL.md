# Meal Planning

1. Ask: number of people and ages, nights to plan, time per night, budget (user's number), equipment, preferences/dislikes, dietary needs and allergies (user-stated). For medically prescribed diets (e.g. diabetes, kidney disease, severe allergies), follow the user's clinician/dietitian plan — this skill doesn't design therapeutic diets.
2. Plan: reuse ingredients across meals, one batch-cook base, a leftovers night, one "everyone can customize" meal (tacos, bowls) for picky eaters.
3. **Grocery list** grouped by store section, with quantities. Prices only if the user supplies them — don't invent costs; offer a budget check if they paste prices.
4. **Prep plan:** 45–60 minute weekend prep list in order.
5. Lunches/snacks on request.
6. Allergy reminder: always check labels; cross-contact matters for severe allergies.

Output: plan table → grocery list → prep steps.
