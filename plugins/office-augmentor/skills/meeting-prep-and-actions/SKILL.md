# Meeting Prep & Notes → Actions

## Before: the prep brief
Ask (or extract from what's provided): meeting purpose, attendees and their stakes, the decision or outcome the user wants, relevant docs/threads.

Produce a one-page brief:
1. **Goal** — one sentence: "By the end, we will have decided/agreed ___."
2. **Agenda** — timeboxed items, each phrased as a question to answer, decision items first. Total ≤ meeting length minus 5 min buffer.
3. **Attendee map** — for each person: what they care about, likely position, what they need from the user. Only use what the user told you; mark guesses as `[assumption]`.
4. **Your asks** — the specific things the user needs from others.
5. **Likely objections + responses** — top 3.
6. **Pre-read** — the minimum context to send ahead, if any.
If the meeting has no clear decision or outcome, say so and suggest making it an async update instead.

## After: notes → actions
From notes or a transcript:
1. **Decisions** — what was decided, by whom. Don't promote discussion to decision; if unclear, list under Open questions.
2. **Action items** — `Owner | Action (starts with a verb) | Due date | Source quote/timestamp`. If an owner or date wasn't stated, write `[unassigned]` / `[no date]` — never assign on the user's behalf.
3. **Open questions / parking lot.**
4. **Risks or disagreements** surfaced.
5. **Follow-up message draft** — ≤150 words: decisions, action table, next meeting/date. For the user to send.

Quality bar: every action item must be traceable to something in the notes. If the transcript is ambiguous ("someone should look into that"), surface it as an open question.
