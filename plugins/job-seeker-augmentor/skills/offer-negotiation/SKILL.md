# Offer Evaluation & Negotiation

## Evaluate
1. Build a comparison table from the user's numbers: base, bonus (target and how paid), equity (type, vesting, strike/grant value — explain that private-company equity value is uncertain), benefits, PTO, retirement match, remote/commute, title, start date, growth.
2. Annualize carefully and show the math. Unknowns → `[DATA NEEDED]`.
3. Non-financial factors weighted by the user's priorities.

## Market data
Never supply salary numbers from memory. Point the user to sources (company-reported pay ranges in postings where required by law, salary surveys, professional associations, peers) and record their source next to each figure: `[DATA NEEDED: market range source]`.

## Negotiate
- Anchor on value and market data; ask for a specific number or package.
- Script: gratitude → enthusiasm → the ask with rationale → pause → handle responses (budget fixed → ask for signing bonus, title, review timing, equity, PTO, start date).
- Email version and call version. Role-play the recruiter (realistic, not a pushover), then debrief.
- Decide the walk-away point in advance.

Not legal advice: non-competes, IP assignment, visa terms, and contract clauses → an employment attorney.
