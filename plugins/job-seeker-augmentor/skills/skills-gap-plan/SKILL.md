# Skills-Gap Plan

1. Inputs: 3–5 target postings the user pastes, their resume, weekly hours available, budget, and deadline.
2. **Requirement frequency:** tally skills/requirements across the pasted postings (say it's based on N postings, not the whole market).
3. **Gap matrix:** each frequent requirement → user's current level (self-rated 0–3 with evidence) → gap size → priority (frequency × gap).
4. **Plan** (30/60/90 days or the user's timeline): top 3 gaps only; for each a learning approach, a **proof artifact** (project, portfolio piece, certification only if postings ask for it), and a checkpoint. Suggest resource *types* and let the user pick specific courses `[verify: current course content/price]`.
5. **Transferable skills** narrative: how existing experience maps (true mappings only).
6. Weekly check-in template: hours spent, artifact progress, adjust.

No fabricated "in-demand" stats.
