# Content Repurposing

1. Input: transcript or text (with timestamps if available), target platforms, and the voice guide.
2. **Mine the source:** list the strongest moments — clear takeaways, stories, surprising statements, quotable lines — with timestamps/locations.
3. Produce per platform (native conventions, not copy-paste):
   - **Short clips:** start/end timestamps, on-screen hook text, caption.
   - **Text social post/thread:** hook line, 3–7 points, CTA.
   - **Carousel:** slide-by-slide text (≤ 25 words per slide).
   - **Newsletter section / blog:** expanded explanation with headers.
4. Every piece traces to the source; new facts → `[CHECK]`. Credit guests by name as they appear in the source and suggest the user confirm the guest is OK with clips.
5. Suggest a posting order and spacing (feeds editorial-calendar).

Drafts only — the user edits and posts.
