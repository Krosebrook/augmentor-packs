# Content Ideation

1. Context: niche, platform(s), audience (who, what they struggle with), goals (growth, community, revenue), past top performers and flops (titles + the user's own numbers if available), production constraints.
2. Generate across angles: questions the audience asks, myths to bust, "how I…" experiences, comparisons/tests, mistakes, contrarian takes, series, collaborations, timely hooks (only if the user names the event/trend — don't invent "trending now").
3. **Score** each idea 1–5 on: audience pull (does it answer a real question?), the user's unique angle, production effort (inverse), and goal fit. Show the table and top 5.
4. For the top picks: working title options, the core promise, and the one thing the viewer will learn/feel.
5. Ask which to develop; hand off to hooks-and-scripts.

Ideas are starting points. The user's taste decides.
