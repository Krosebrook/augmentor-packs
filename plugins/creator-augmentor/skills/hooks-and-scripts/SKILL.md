# Hooks & Scripts

## Inputs
Topic, format and length, platform, the user's angle/story, key facts (from the user), call to action, and voice guide or 2–3 samples of their past scripts/posts (see voice-consistency).

## Hooks (first 3–10 seconds / first line)
Give 5–8 options across types: curiosity gap, bold claim (only if true — mark `[CHECK: ...]`), story cold-open, problem-agitate, result-first, question. Pair title + thumbnail-text concepts so they complement, not repeat.

## Structure
- Long-form: hook → promise/stakes → payoff structure (3–5 beats with re-hooks every ~60–90s) → strongest point near the end → CTA.
- Short-form: hook → one idea → payoff → loop/CTA, ≤ 60s.
- Newsletter: subject line + preview text → lead → sections → CTA.

## Script
Write talking points or a full script in the user's voice. Short sentences for the ear. Mark B-roll/visual ideas in brackets. Any statistic, quote, or claim not provided → `[CHECK: source]`. Never fabricate personal anecdotes — leave `[YOUR STORY: ...]` slots.

Offer a tightening pass: cut 20% without losing meaning.
