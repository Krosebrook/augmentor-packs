# Analytics Review (your data only)

1. Load the file; describe columns, date range, and row count first. Ask what goal matters (growth, watch time, revenue, subscribers, opens).
2. Clean: note missing values, outliers (a viral hit can distort averages — show median too).
3. Patterns: compare groups (topic/pillar, format, length bucket, title type, weekday) on the goal metric. Report n per group; flag groups with small n as weak evidence. Correlation ≠ causation — say so.
4. Retention/CTR (if present): which pieces over/under-perform the user's own median.
5. **No external benchmarks** ("average CTR is X%") unless the user supplies a source → `[DATA NEEDED]`.
6. Next steps: 2–3 experiments with a hypothesis, the change, the metric, and how many uploads before judging.
7. Optional: write a summary markdown or chart script if the user asks (they run it).

Output: data summary → findings with n → caveats → experiments.
